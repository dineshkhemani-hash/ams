"I created the Role entity class to map the roles table in our database using JPA/Hibernate ORM.
This entity represents the different user roles in our authorization system, like ADMIN or USER, which control application permissions. 
By using a strongly typed enum (ERoles) instead of strings, we prevent typos and ensure only valid roles are assigned.
I deliberately included a getter but not setter for the ID field since IDs are generated by the database, while the role name needs both getter and setter for business logic. 
This entity class serves as a foundational part of our security model, allowing us to assign and check user permissions throughout the application."
